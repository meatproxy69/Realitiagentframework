# Local data and reporting

This browser package has no remote transport or upload endpoint. Keep resident notes, browser profiles, key material, raw continuity histories, and private learned state out of reports and contributions. Report defects with a minimal synthetic reproduction and artifact SHA-256 to the project owner through a private channel.

Application deletion covers its own local storage namespace and key database. It does not erase browser backups, screenshots, copied exports, or external records. Local profile access and injected browser scripts are outside the resident API's authority boundary. See README.md for storage and reset behavior.
