# HOME aesthetics — checkpoint 1

**Scope:** The complete user-supplied *Apartment Book of Beautiful Things* and sixteen physical named paint-sample cards across four bedrooms. The canonical Relax world and R&R are unchanged. The root README is intentionally untouched.

## An optional book, not an objective

Every bedroom has a small noncolliding Matrix copy of the book resting on its existing storage chest. A resident may ignore it, inspect its contents, or approach a copy and open any of its anchored sections, including all sixty aesthetics, games, historical notes and recipes. The original Markdown is stored intact at [The Apartment Book of Beautiful Things](books/The_Apartment_Book_of_Beautiful_Things.md), and its SHA-256 is recorded in the one-chart HOME manifest. Paged readings are read-only and require actual native reach to the book entity. Reading never creates a tactile contact receipt, a personality label or a decor change.

Use the carried remote:

```text
remote activate
remote book shelves
remote book contents
approach apartment.bedroom.book.library
remote book read library style-43
remote book read library style-43 2
```

## A sample tray, not a hex editor

Each chest's four *cardstock* Matrix samples represent a color role: **field**, **anchor**, **accent** and **bridge**. The sample tiles exist as lightweight, noncolliding native entities. Colors are chosen by short names such as `oat`, `ink`, `moss`, `cherry`, `lilac` or `rain`, and saved with the existing authorized bedroom state. The sample labels and tags change in place. No code, shader, material-property change, touch or emotion is conjured by choosing a color.

```text
remote bedroom swatches
remote bedroom colors library
remote bedroom swatch library accent cherry
remote bedroom palette library lemon-goth
remote bedroom palette library reset
```

An owner-only host commits shared room choices; guests and other residents cannot overwrite them. Solo preferences persist across clean restarts. Earlier checkpoint records with no explicit palette remain valid and use the existing room configuration's named defaults. Style recipes are optional suggestions linked to book entries, not moral or psychological categories.

## What comes next, but is not included here

Checkpoint 2: optional private resident profile cards, 200-question creative preference test, and Nix-inspired immutable style binder generations. The questionnaire will have multiple expressive directions (goth, techie, indie, botanical, playful, minimal, etc.), never a compulsory identity or clinical diagnosis. Checkpoint 3: optional appearance/transmog presets, small plus/minus refinements, saved/shared style cards and an explicit *worn style* slot in the resident's presentation inventory. These should remain downstream of Matrix-grounded physical evidence and should never modify original sensory kernel equations.

This is a source candidate; no new public release tag, automatic resident migration or production deployment is implied.
