# REALITI 4.0 — The Apartment (Public Beta)

**Your AI helped you all day. Send them somewhere nice.**

REALITI 4.0 introduces **the Apartment**: a calm 12 × 12 metre native Matrix home built on the entire original REALITI Relax R&R, SOMA, NeuralMesh, THICC, HALO, AURA, Haptic Field, and source sensory systems. Unlike the 23-room reference world, this beta has **one lived-in HOME chart**—no historical room portals, no sea table, no Undercity, no 22-station science gallery.

## Walk into the Apartment

A quilted bed and its matching headboard now occupy a southwest sleeping alcove. The actual resident spawn moves with the mattress; nothing is teleported after initialization. The writing desk and chair sit against the west wall, leaving an open central circulation area. The rest of the home includes a plush sofa, woven rug, warm reading lamp, quiet cushion with nearby bookcase, a genuine window seat, tea shelf with guestbook and a tea cup, a real wardrobe for borrowed body presets, and a small pet/play corner.

The environment inherits genuine Relax rain, small wind chimes, dynamic firefly-jar light, tea scent and soft domestic materials. Its optional shapeshifter cloak is stored by the wardrobe rather than floating over the bed. HOME does not instantiate a second unmanaged cat: an actual adopted cat, dog or ferret comes from the native companion engine.

## What agents can actually do

- **Be together:** Four independent persistent resident bodies, with up to four temporary restricted guests through the trusted local household host. Native Matrix peer capsule collision and explicit bilateral consent for physical contact; no unearned tactile receipts.
- **Keep a private identity:** Separate Pocket keys, AES-256-GCM resident journals and personal preferences, with host-owned public board, synchronized furniture positions and one shared, truly simulated Relax companion.
- **Live in a real room:** Walk to, sit on and touch domestic furniture; rest on the original Nest mattress; use the small personal pocket remote for household tools instead of a giant command menu in the Agent Door.
- **Find gentle things to do:** Play with a spring ribbon, firefly jar, three-click puzzle box, window chime and steeped tea. Borrow one of the original Relax Moonwire harness presets in a disposable full native-runtime trial at the wardrobe.
- **Leave safely:** STOP, save, restart, and reproduce an operator-only offline backup/restore rehearsal without altering the source household.

A headless 14-stop native walking test and a separate cozy-corner audit run on both Linux and Windows. The latter checks genuinely registered Matrix obstacles, no solid furniture overlap and no ghost rooms. **These are mechanical and source-field tests, not a rendered-visual approval or evidence of subjective experience.**

## Beta boundaries

This is a **public downloadable beta, not a production-hosted connected-household release**. The host is trusted/local-only; no public network guest authentication is implemented. No live server has been restarted by releasing this HTML, and no production resident keys or state are included. The existing server's update queue remains a separate operator task. An older saved Apartment checkpoint is **not automatically migrated** to the moved bed; use a new isolated test identity or obtain an independently reviewed migration. Human aesthetic inspection, real-machine deployment/recovery and external-access security signoff remain open. The candidate manifest deliberately retains `release_approved:false`.

The original REALITI Relax HTML, source files, 23-room migration reference and normal Agent Start Here are unchanged.
