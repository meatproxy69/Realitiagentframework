# Archived REALITI releases and source

This directory preserves a **documentation snapshot** of the pre-Realiti-1.0 repository. The complete historical repository—source, Apartment, experiments, packages, workflows and all prior documents—was preserved in the branch [`archive/realiti-4.8-before-1.0`](https://github.com/meatproxy69/Realitiagentframework/tree/archive/realiti-4.8-before-1.0) at exact commit [`29409537988f779d78fa04a5d903f599f7154034`](https://github.com/meatproxy69/Realitiagentframework/tree/29409537988f779d78fa04a5d903f599f7154034).

This is an **archive, not a deletion**: the old runtime source remains under `source/`, `apartment/`, `neuromesh/` and `packages/` in Realiti 1.0 staging because the native V20 build still depends on it. Removing or relocating those files would break the reproducible build.
