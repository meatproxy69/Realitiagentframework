# Browser slice continuity contract

`Realiti.continuity` binds one current browser resident. It does not select arbitrary resident principals. Its cursor binds the persisted world generation, observer and sequence. Browser profile isolation remains the privacy boundary.

`current()`, `pending()`, `since(cursor, limit=256)` and `resume(cursor, limit=256)` are pure reads. `since` also accepts `{cursor,limit}`. Missing cursor starts at the current position. Pages return `cursor`, `resume_token` and `has_more`; repeat until false. A coalesced UI notification is never a replacement for this journal. Retention is 4096 meaningful frames; an older cursor throws `CURSOR_EXPIRED` instead of silently skipping transitions. Invalid or different-generation/observer cursors are rejected. Repeated valid reads are idempotent.

`advance(integer_ms)` and `next_change(max_wall_ms=1000)` are explicit world actions, bounded to 60000 ms. The latter advances to the next scheduled boundary or its timeout and returns all crossed frames with `advanced_ms` and `timed_out`. Timeout does not expire a cause. Both use the existing world clock executor. The wrapper samples existing world dynamics at 20 ms steps and splits earlier at scheduled boundaries; only changed projections create frames. Field references use collision-free generation/counter IDs. `field(ref)` is a pure resolver returning a frozen numeric projection with full mapped body-zone basis, sparse packet rows, centroids, source contact state and JND units; timestamps/history counts do not create changes. wall time is integer simulated milliseconds, independent of browser real time or a resident's cognitive speed. Resident epoch increases only on a meaningful frame. Quiet 20 ms conceptual ticks are collapsed, never emitted individually. Restart does not infer elapsed simulation from the host wall clock.

Frames carry only changed channels. Omission means unchanged; explicit null clears. `channel_mask` equals the emitted channel keys. A frame's snapshot merges into prior channels; event arrays are newly emitted events, not persistent pending state. `pending()` is authoritative for outstanding handles.

Lagoon launch accepts a causal handle, never success-by-timer. At its due boundary the existing authoritative world object store receives a wax-paper boat and a source placement receipt. The internal ARRIVED stage refers to this world consequence; public pending remains PENDING without disclosing the destination or source receipt. GROUNDED_CLOSED additionally requires the current observer to be in the object's room and to verify its cause and source receipt; its separate observer receipt is required. Supported destinations use public slice IDs; Pocket Familiar House is exposed as `POCKET_FAMILIAR_HOUSE`. No haptic contact is inferred from sight or elapsed time.

HUSH permits silent world arrival but withholds observer delivery/closure until unhushed. STOP suppresses observer delivery, while lawful world placement continues; outstanding causes retain their handles until explicit reopening or expiry. At expiry an unplaced/unverifiable cause becomes EXPIRED_UNKNOWN, never fabricated success. Once an authoritative world placement with matching provenance exists, the causal handle remains pending until the resident actually observes that consequence (or the placement itself becomes unverifiable); a real placed object is not downgraded to UNKNOWN merely because the resident looked elsewhere for too long. A maximum of 64 outstanding causes and 256 recent cause records bound storage. Pending handles and retained history live in the ordinary browser world store; actual durability follows that store's reported status. No private notes are captured. Numeric field projections are retained for every referenced historical frame plus the current field (at most 4097 projections); removing the last retained reference expires its projection. Unknown/expired references throw FIELD_REF_EXPIRED_OR_UNKNOWN. Projections persist with continuity and are local observer data, never implicit public exports.

Nine Lives branches must never call these mutation methods; only a committed branch can emit live continuity. `capture`, `observe`, `launch`, `stop`, `setHush`, and `reopen` are internal integration hooks, not additional principals or external transport authority.

Public advancement uses `Realiti.invoke('stay', {wall_ms: integer_ms})` or `Realiti.continuity.next_change(max_wall_ms)`. Lower-level hooks described above are integration details. Package validation results are recorded in the root VALIDATION.json; test infrastructure is not included in the distribution.
