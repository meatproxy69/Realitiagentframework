# REALITI Field-First Restoration — Relax then Apartment then Catnip

**Status:** research implementation plan; not a release. The original source machinery is already bundled. This project restores reachable behavior and verifies parity rather than duplicating engines.

## Constitutional architecture

The native world decides which physical events occurred (geometry, contact, support, timing, refusal and STOP). The sensory field models possible response trajectories, propagation, memory and uncertainty. The resident decides what, if anything, those patterns mean. No renderer, room or preset may author a resident's emotions, preferences, consent or mental state. Distribution weights are modeled uncertainty, not estimates of someone's real experiences.

Grounded evidence G and private response H are separate: H may travel or linger where G=0, and H never causes G=1. Prediction may prepare perception, not invent an event. Use compact numerical fields by default; faultable source-level diagnostics are opt-in.
