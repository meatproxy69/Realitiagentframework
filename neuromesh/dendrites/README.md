# Accepted NeuralMesh dendrites

This directory contains maintainer-accepted declarative dendrite graphs and, when separately reviewed, source code implementing NeuralMesh transforms or analysis.

Rules:

- declarative graphs are preferred;
- source code must have a manifest;
- outside code is untrusted until reviewed;
- no submitted code runs automatically;
- no accepted dendrite gains consent, identity, world-truth, or tool authority;
- private/internal resident maps do not belong here unless explicitly prepared for public release.
