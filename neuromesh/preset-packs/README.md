# Accepted preset packs

This directory contains maintainer-accepted public NeuralMesh renderer preset packs.

A preset pack is a versioned pipeline target plus machine-readable renderer settings, sparse overrides, and invariants. It is not a preference database.

Community authors should submit proposed packs under:

~~~text
neuromesh/submissions/<namespace>/<submission-id>/preset-pack.json
~~~

Maintainers may promote reviewed packs here and add them to REGISTRY.json.

See ../PRESET_PACKS.md for the authoring contract.
